# Цикл 07 · v3.4 — Вход с других компьютеров сети

Дата: 2026-10-08

## Запрос

- Всё работает, но другие люди в той же сети не могут войти: форму видят, вход не проходит.

## Что сделано

- Сервер ищет токен по порядку: заголовок окна → параметр ?s= (если прокси вырезает заголовки) → HttpOnly-cookie (если браузеру запрещено хранилище сайта).
- Токен хранится и в памяти окна — вход работает даже без sessionStorage/localStorage.
- Понятное сообщение, если сервер принял пароль, а браузер не передаёт данные входа.

## Ревью и QA

- Найдено: на других ПК (политики браузера запрещают хранилище сайта, прокси вырезает заголовки) вход «молча» не проходил. Проверено в 7 комбинациях ограничений, в т.ч. по IP из сети.
