# Цикл 03 · v3.0 — Проверка ФИО, старшие с ограниченным списком ТТ, доп. ответственный

Дата: 2026-10-04

## Запрос

- Блокировки при входе инженера: цифры, меньше двух слов, пустое поле; предупреждение, что работа под вымышленным ФИО не засчитывается.
- Старшие, которым можно выделить только определённые ТТ.
- Доп. ответственный у пунктов подготовки — назначает только администратор, вписать вручную или выбрать из списка.

## Что сделано

- checkFio в общем модуле: одна проверка на сервере и в браузере, ввод цифр блокируется прямо в поле.
- Выбор ТТ для старшего по городам с поиском; сервер фильтрует данные, Excel и сводку по назначенным ТТ.
- Доп. ответственный (datalist из пользователей и уже назначенных людей), колонка в Excel подготовки.

## Ревью и QA

- Проверены права: ограниченный старший не видит чужие ТТ ни в списке, ни по прямой ссылке API.
