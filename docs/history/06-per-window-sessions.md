# Цикл 06 · v3.3 — Несколько окон: отдельная сессия в каждом окне, полный QA

Дата: 2026-10-08

## Запрос

- При работе в нескольких окнах сбрасываются данные в ячейках: создаю пользователя, меняю ему магазины — всё исчезает. Перепроверить весь сайт на такие баги, полный QA.

## Что сделано

- Сессия на окно: токен в памяти и sessionStorage, заголовок X-KSO-Token; вход в соседнем окне больше не подменяет пользователя.
- Токен также передаётся параметром ?s= для картинок, файлов Excel и потока событий.
- Отключено автозаполнение паролей браузером в формах пользователей.
- Плашка «нет связи с сервером» вынесена из страницы и пропадает сразу после восстановления связи.

## Ревью и QA

- Найдено: все окна делили одну cookie-сессию — вход другим пользователем в соседнем окне «перехватывал» первое окно.
- Найдено: плашка «нет связи» оставалась, пока в поле стоял курсор (перерисовка была отложена).
- Автотест Playwright: несколько окон с разными ролями, заполненные формы переживают действия в других окнах.
