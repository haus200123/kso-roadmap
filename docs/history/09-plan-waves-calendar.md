# Цикл 09 · v4.0 — План установки по волнам, календарь, быстрые правки, ККТ двух типов

Дата: 2026-10-14

## Запрос

- Переработать ТТ по файлу «План установки КСО»: ничего не удалять (пользователи, фото, галочки, внесённое), создать новые ТТ и поправить существующие.
- Замечания к шаблону: «Снять колонки с NCR и звуковые карты»; ККТ Кварц 2Ф с демонтажа и новые Нова Принт; к Z-отчётам — «Убедиться, что все чеки есть в POSCore и УчётПлюс»; проверить и показать персоналу подтверждение возраста через МАХ; сообщать 2ЛТП о новых и о снимаемых кассах; сообщить второй линии о нужных лицензиях.
- Календарь для старших и админа: какие ТТ в какие даты.
- Поле «Город» при создании ТТ уезжало в адрес; неудобная правка пунктов — нужны ✎, ✕ и «＋»; быстрая правка количеств касс, демонтажа и ККТ по типам с авторасчётом.
- Опрос: все ТТ с работами по плану; ТТ не из плана — как есть; вкладки волн — 1 и 2 волна, админ создаёт и удаляет вкладки.

## Что сделано

- Перенос базы при первом запуске: копия базы, разовая загрузка плана (совпавшие по адресу ТТ обновляются, остальные создаются), ТТ из обеих волн — две карточки.
- Шаблон версии 3 с ключами пунктов: при пересчёте количеств пункты добавляются/убираются, а отметки, комментарии, фото и правки текста сохраняются; удалённые админом пункты не возвращаются.
- Вкладки волн (создать/переименовать/удалить, ТТ при удалении — в «Без волны»), календарь месяца со списком на телефоне, сводка заказа и Excel по волне.
- Панель «Количество касс и ККТ» с кнопками −/+; авторасчёт: Кварц 2Ф = снимаемые кассы, остальное — Нова Принт; ручная правка выключает авторасчёт.
- ✎/✕ у пунктов и «＋ пункт» у групп в обычном режиме; форма новой ТТ: сначала город, потом адрес, предупреждение и автоисправление перепутанных полей.

## Ревью и QA

- Найдено на ревью: при переносе старых чек-листов сопоставление пунктов по id сдвигалось, если количества меняли без пересоздания — переделано на сопоставление по тексту, затем по id.
- Найдено: для S.kit, уже стоящих на ТТ, появлялся бессмысленный пункт «Согласовать перемещение» — убран.
- Найдено: добавленный пункт не появлялся, пока курсор оставался в поле добавления (перерисовка отложена) — поле теряет фокус перед сохранением.
- Найдено: 6 вкладок не помещались в шапку на 1300px — перенос вкладок на вторую строку до 1440px; панель количеств свёрнута по умолчанию.
- QA: 79 новых проверок (перенос данных без потерь, волны, календарь, быстрые правки, ККТ, Excel, инженер) + 123 прежних, в т.ч. по IP из сети.
