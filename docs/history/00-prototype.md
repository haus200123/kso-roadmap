# Цикл 00 · v0-prototype — Кликабельный прототип

Дата: 2026-10-01

## Запрос

- Есть ТЗ и таблица установки КСО по магазинам. Нужен кликабельный прототип, где можно менять количество касс для установки, демонтажа и остального.

## Что сделано

- Одностраничный прототип без сервера: сводка по ТТ, фильтры, таблица, карточка ТТ с количествами, таймлайн, сводка заказа.
- Количества касс (S.kit, CSIK, NCR, ККТ, терминалы, колонки) правятся прямо в карточке и сразу пересчитывают сводку.

## Ревью и QA

- Показан заказчику, по итогам — решение упростить меню до двух разделов и сделать рабочий сайт.
