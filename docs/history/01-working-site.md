# Цикл 01 · v1 — Рабочий локальный сайт: два раздела, роли, Excel

Дата: 2026-10-01

## Запрос

- Упростить до двух пунктов меню: «Отработка по ТТ» и «Подготовительные действия по ТТ».
- ТТ — раскрывающимся списком, справа редактируемая дата, у каждой ТТ ответственный и чек-лист; выгрузка чек-листа в Excel с квадратиками для галочек.
- Роли: администратор, старший, инженер (входит по ФИО без пароля, его отметки уходят старшему на подтверждение). «Запомнить меня» на 72 часа.
- Запуск на любом ПК одним Start.bat, база локальная, папка сайта и папка данных отдельно, в окне запуска виден IP-адрес.
- Опрос: Node.js скачивается при первом запуске; только локальная сеть; пользователей ведёт администратор на сайте; ежедневные копии, журнал действий, сводка заказа по юрлицам.

## Что сделано

- Сервер на Node.js без внешних зависимостей (http, fs, crypto), база data/db.json с атомарной записью.
- Сессии, вход админа/старшего по паролю (scrypt), инженера по ФИО; подтверждение отметок инженера старшим, колокольчик «на проверку».
- Живые обновления через SSE, фото к пунктам, журнал, ежедневные резервные копии, сводка заказа и Excel без библиотек (свой генератор xlsx).
- Start.bat: находит Node.js или скачивает переносной с nodejs.org с проверкой SHA-256.
