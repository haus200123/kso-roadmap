ДОРОЖНАЯ КАРТА КСО — локальная версия 3.5
=====================================

ЗАПУСК
1. Скопируйте папку KSO-Roadmap на компьютер, который будет сервером
   (Windows 10 или 11). Путь лучше без пробелов и русских букв, например C:\KSO-Roadmap
2. Дважды щёлкните Start.bat.
   При первом запуске он скачает Node.js (около 30 МБ) в папку site\runtime —
   нужен интернет. Дальше сайт работает без интернета.
3. Windows спросит разрешение для node.exe в брандмауэре — отметьте
   «Частные сети» и нажмите «Разрешить доступ». Без этого с других
   компьютеров и телефонов сайт не откроется.
4. В окне появится адрес вида  http://192.168.1.25:8080  — откройте его
   в браузере на любом компьютере или телефоне в той же сети (Wi-Fi или кабель).
   На самом сервере сайт откроется автоматически.
5. Пока сайт работает, окно Start.bat не закрывайте. Закрыли окно — сайт остановлен.

ВХОД
  Администратор:      логин Admin   пароль admin
  Старший сотрудник:  логин ITlead  пароль lead
  Инженер:            без пароля — вписать фамилию и имя, «Войти как инженер»
                      (только буквы, минимум два слова, без цифр)
  Старшим можно ограничить список ТТ: «Пользователи» → «Изменить» → снять
  «Все ТТ» и отметить нужные. Старший увидит только свои ТТ.
  Смените пароли после первого входа: раздел «Пользователи».
  «Запомнить меня» держит вход на устройстве 72 часа.

НЕСКОЛЬКО ОКОН
  Каждое окно (вкладка) браузера входит отдельно: в одном окне можно быть
  администратором, в другом — старшим или инженером, они не мешают друг другу.
  С «Запомнить меня» новые окна открываются сразу под запомненным пользователем.
  После обновления до версии 3.4 всем нужно один раз войти заново.

ШАБЛОН ЧЕК-ЛИСТОВ
  Шаблон один и не меняется. Правки пунктов и подпунктов в любой ТТ касаются
  только этой ТТ. Новая ТТ и кнопка «Пересоздать из шаблона» всегда берут
  исходный шаблон.

ЧТО ГДЕ ЛЕЖИТ
  Start.bat           — запуск сайта
  site\               — сам сайт (программа). Можно заменить на новую версию,
                        данные при этом не пострадают
  site\runtime\       — Node.js (появится после первого запуска)
  data\               — все данные. Её и нужно беречь:
     db.json           — база: ТТ, чек-листы, отметки, пользователи (пароли зашифрованы)
     photos\           — фото, приложенные к пунктам
     journal.log       — журнал действий: кто, когда, что сделал, с какого IP
     sessions.json     — активные входы
     config.json       — настройки: порт (по умолчанию 8080), сколько дней хранить копии
     backups\          — копия базы и журнала раз в сутки (хранятся 14 последних)
                        и архив всех фото (backups\photos)

ОБНОВЛЕНИЕ НА НОВУЮ ВЕРСИЮ
  1. Закройте окно Start.bat.
  2. Замените папку site на новую (папку data не трогайте).
  3. Запустите Start.bat. Пользователи, даты, ответственные и журнал сохранятся.
     При переходе с версии 1 на 2 и 3 чек-листы всех ТТ один раз пересоздаются
     по новому шаблону (старые отметки, фото и комментарии сбрасываются).
     С версии 2 на 3 ничего не сбрасывается.

ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР
  Остановите сайт и скопируйте всю папку KSO-Roadmap целиком.

ВОССТАНОВЛЕНИЕ ИЗ КОПИИ
  1. Закройте окно Start.bat.
  2. Скопируйте data\backups\<дата>\db.json поверх data\db.json.
  3. Запустите Start.bat.

ЕСЛИ НЕТ ИНТЕРНЕТА ПРИ ПЕРВОМ ЗАПУСКЕ
  На другом компьютере скачайте с https://nodejs.org/en/download архив
  «Windows Binary (.zip)», достаньте из него node.exe и положите в site\runtime\

ЕСЛИ СТРАНИЦА НЕ ОТКРЫВАЕТСЯ С ДРУГОГО УСТРОЙСТВА
  — устройство должно быть в той же сети, что и сервер;
  — проверьте брандмауэр: Панель управления → Брандмауэр Защитника Windows →
    Разрешение взаимодействия с приложением → Node.js → галочка «Частные»;
  — если сеть в Windows помечена как «Общественная», переключите её на «Частная».
  — порт занят: сайт сам возьмёт следующий (8081, 8082…), смотрите адрес в окне.

ВАЖНО
  Сайт работает по http внутри локальной сети. Не открывайте его наружу
  в интернет без VPN или HTTPS.
