# Автотесты

Тесты поднимают сайт (`node site/server.js`) в указанной копии проекта и проходят его в Chromium через Playwright. Порт 8080 должен быть свободен.

| Файл | Что проверяет |
|---|---|
| `qa.js` | Вход и сессии, несколько окон с разными ролями, сохранность заполняемых форм, права доступа, рабочие сценарии (отметки, подтверждение, комментарии, фото, Excel), перезапуск сервера, удаление и редактирование, все экраны всех ролей на ПК и телефоне, тёмная тема |
| `qa9.js` | Обновление базы версии 3.5 (`fixtures/db-v3.5.json`) до версии 4 без потерь, вкладки волн, календарь, быстрые правки пунктов, количества и ККТ, сводка по волне, Excel, инженер, наблюдатель |

```bash
npm i -g playwright && npx playwright install chromium
cp -r .. /tmp/kso-a && NODE_PATH=$(npm root -g) node qa.js /tmp/kso-a
cp -r .. /tmp/kso-b && NODE_PATH=$(npm root -g) node qa9.js /tmp/kso-b
```

Вторым аргументом можно передать IP компьютера, чтобы проверить работу по сети: `node qa.js /tmp/kso-a 192.168.1.25`.
Скриншоты и результаты пишутся в `qa/out*/`. `qa9.js` отказывается запускаться, если в копии уже есть `data/db.json`.
