# История версий

Каждая версия — отдельный цикл: запрос → реализация → ревью и QA. Подробности — в [docs/history](docs/history).

## v3.4 — Вход с других компьютеров сети (2026-10-08)

- Сервер ищет токен по порядку: заголовок окна → параметр ?s= (если прокси вырезает заголовки) → HttpOnly-cookie (если браузеру запрещено хранилище сайта).
- Токен хранится и в памяти окна — вход работает даже без sessionStorage/localStorage.
- Понятное сообщение, если сервер принял пароль, а браузер не передаёт данные входа.

Ревью и QA:
- Найдено: на других ПК (политики браузера запрещают хранилище сайта, прокси вырезает заголовки) вход «молча» не проходил. Проверено в 7 комбинациях ограничений, в т.ч. по IP из сети.

## v3.3 — Несколько окон: отдельная сессия в каждом окне, полный QA (2026-10-08)

- Сессия на окно: токен в памяти и sessionStorage, заголовок X-KSO-Token; вход в соседнем окне больше не подменяет пользователя.
- Токен также передаётся параметром ?s= для картинок, файлов Excel и потока событий.
- Отключено автозаполнение паролей браузером в формах пользователей.
- Плашка «нет связи с сервером» вынесена из страницы и пропадает сразу после восстановления связи.

Ревью и QA:
- Найдено: все окна делили одну cookie-сессию — вход другим пользователем в соседнем окне «перехватывал» первое окно.
- Найдено: плашка «нет связи» оставалась, пока в поле стоял курсор (перерисовка была отложена).
- Автотест Playwright: несколько окон с разными ролями, заполненные формы переживают действия в других окнах.

## v3.2 — Исправлено создание ТТ и пользователей, формы не сбрасываются (2026-10-08)

- Исправлено создание ТТ (с пустыми полями количеств считаются авто-значения) и пользователей.
- Черновики форм: введённое не теряется, когда страница обновляется по живым данным; перерисовка только при изменении версии данных.

Ревью и QA:
- Найдено: опрос сервера раз в 30 с и события SSE перерисовывали страницу и стирали заполняемые поля — исправлено черновиками и отложенной перерисовкой.

## v3.1 — Демонтаж линейных касс (2026-10-04)

- Новое количество «демонтаж лин. касс»: учитывается в пунктах демонтажа, ККТ/терминалах с демонтажа и сводке заказа.

## v3.0 — Проверка ФИО, старшие с ограниченным списком ТТ, доп. ответственный (2026-10-04)

- checkFio в общем модуле: одна проверка на сервере и в браузере, ввод цифр блокируется прямо в поле.
- Выбор ТТ для старшего по городам с поиском; сервер фильтрует данные, Excel и сводку по назначенным ТТ.
- Доп. ответственный (datalist из пользователей и уже назначенных людей), колонка в Excel подготовки.

Ревью и QA:
- Проверены права: ограниченный старший не видит чужие ТТ ни в списке, ни по прямой ссылке API.

## v1 — Рабочий локальный сайт: два раздела, роли, Excel (2026-10-01)

- Сервер на Node.js без внешних зависимостей (http, fs, crypto), база data/db.json с атомарной записью.
- Сессии, вход админа/старшего по паролю (scrypt), инженера по ФИО; подтверждение отметок инженера старшим, колокольчик «на проверку».
- Живые обновления через SSE, фото к пунктам, журнал, ежедневные резервные копии, сводка заказа и Excel без библиотек (свой генератор xlsx).
- Start.bat: находит Node.js или скачивает переносной с nodejs.org с проверкой SHA-256.

Ревью и QA:
- Ручная проверка сценариев всех трёх ролей и выгрузки Excel.

## v0-prototype — Кликабельный прототип (2026-10-01)

- Одностраничный прототип без сервера: сводка по ТТ, фильтры, таблица, карточка ТТ с количествами, таймлайн, сводка заказа.
- Количества касс (S.kit, CSIK, NCR, ККТ, терминалы, колонки) правятся прямо в карточке и сразу пересчитывают сводку.

Ревью и QA:
