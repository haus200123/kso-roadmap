# История версий

Каждая версия — отдельный цикл: запрос → реализация → ревью и QA. Подробности — в [docs/history](docs/history).

## v3.1 — Демонтаж линейных касс (2026-10-04)

- Новое количество «демонтаж лин. касс»: учитывается в пунктах демонтажа, ККТ/терминалах с демонтажа и сводке заказа.

## v3.0 — Проверка ФИО, старшие с ограниченным списком ТТ, доп. ответственный (2026-10-04)

- checkFio в общем модуле: одна проверка на сервере и в браузере, ввод цифр блокируется прямо в поле.
- Выбор ТТ для старшего по городам с поиском; сервер фильтрует данные, Excel и сводку по назначенным ТТ.
- Доп. ответственный (datalist из пользователей и уже назначенных людей), колонка в Excel подготовки.

Ревью и QA:
- Проверены права: ограниченный старший не видит чужие ТТ ни в списке, ни по прямой ссылке API.

## v2 — Подзадачи, комментарии, подробный шаблон и инструкции (2026-10-04)

- Шаблон чек-листов версии 2: группы, подзадачи, ссылки «📘 Инструкция» на каждый шаг настройки.
- Комментарии к пунктам и подпунктам, подзадачи (добавить/переименовать/удалить), автозакрытие пункта по подзадачам.
- Версионирование шаблона: при переходе на новую версию чек-листы пересоздаются.

Ревью и QA:
- Проверены тексты шаблона по инструкциям, вид Excel с подзадачами (1.1, 1.2…).

## v1 — Рабочий локальный сайт: два раздела, роли, Excel (2026-10-01)

- Сервер на Node.js без внешних зависимостей (http, fs, crypto), база data/db.json с атомарной записью.
- Сессии, вход админа/старшего по паролю (scrypt), инженера по ФИО; подтверждение отметок инженера старшим, колокольчик «на проверку».
- Живые обновления через SSE, фото к пунктам, журнал, ежедневные резервные копии, сводка заказа и Excel без библиотек (свой генератор xlsx).
- Start.bat: находит Node.js или скачивает переносной с nodejs.org с проверкой SHA-256.

Ревью и QA:
- Ручная проверка сценариев всех трёх ролей и выгрузки Excel.

## v0-prototype — Кликабельный прототип (2026-10-01)

- Одностраничный прототип без сервера: сводка по ТТ, фильтры, таблица, карточка ТТ с количествами, таймлайн, сводка заказа.
- Количества касс (S.kit, CSIK, NCR, ККТ, терминалы, колонки) правятся прямо в карточке и сразу пересчитывают сводку.

Ревью и QA:
- Показан заказчику, по итогам — решение упростить меню до двух разделов и сделать рабочий сайт.
